# 📁 Public Directory

This folder holds all public static assets served by Vite directly at the root URL (e.g. `https://vezham.com/favicon.ico`).

## 🗂️ What's Inside

### 🌐 SEO & Crawler Files
* [`sitemap.xml`](file:///Users/devchauhan/Documents/Website/vezham/public/sitemap.xml): The primary sitemap. Generated dynamically during the build step.
* `og/`: Open Graph images for each page route (generated during build).
* [`robots.txt`](file:///Users/devchauhan/Documents/Website/vezham/public/robots.txt): Configured to guide search crawlers correctly, pointing to the sitemap.

### 🖼️ Branding & Visuals
* `favicon/`: Multi-resolution favicon files, Apple touch icon, and web manifest.
* `readme-banner.png`: Banner image used across GitHub READMEs.
* `vezham.png` / `icon-*.webp`: Main logo variants used across documentation and readmes.

### 📦 Downloads & Utilities
* [`vezham-icons.zip`](file:///Users/devchauhan/Documents/Website/vezham/public/vezham-icons.zip): Compressed ZIP package containing all raw SVG files (`outline` and `filled` folders) for developers and designers to download.
* [`cheatsheet.html`](file:///Users/devchauhan/Documents/Website/vezham/public/cheatsheet.html): Interactive list of all icons with instant copy options.

### 🤖 LLM & Context Files
* [`llms.txt`](file:///Users/devchauhan/Documents/Website/vezham/public/llms.txt): A structured text file optimized for LLMs (like Cursor, Gemini, Copilot) to quickly understand how to write and install Vezham.
* [`llms-full.txt`](file:///Users/devchauhan/Documents/Website/vezham/public/llms-full.txt): Deep structural context of the Vezham codebase for advanced AI-driven programming queries.
